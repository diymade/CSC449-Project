# Movie Theater Seat Reservation System

## Project Overview

The Movie Theater Seat Reservation System is a course-based software development project designed to demonstrate the analysis, design, implementation, and testing of a movie theater reservation system.

The system is designed to allow customers to view movie showtimes, view available seats, select seats, make reservations, view ticket prices, receive booking confirmations, and cancel reservations.

## Project Features

* View movie showtimes
* View available and reserved seats
* Select available seats
* Make seat reservations
* Prevent duplicate or invalid reservations
* Display total ticket prices
* Provide reservation confirmation
* View wheelchair-accessible seating
* Cancel reservations
* Manage movies, showtimes, pricing, and seating
* Track available and reserved seats

## Project Development

The project follows a four-week development plan:

### Week 1 - Requirements

* Organize project requirements
* Develop user stories and scenarios
* Create the initial project backlog

### Week 2 - Analysis and Design

* Develop the system architecture
* Create the object model
* Create required UML diagrams

### Week 3 - Implementation and Testing

* Implement a selected portion of the system in Java
* Test the implemented functionality
* Identify and document issues

### Week 4 - Final Development

* Continue implementation and testing
* Address identified defects
* Complete project documentation and final report

## Project Goal

The goal of this project is to create a course-based prototype that demonstrates the software development process for a Movie Theater Seat Reservation System using object-oriented analysis, UML design, Java implementation, and testing.
